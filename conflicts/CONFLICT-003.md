# 衝突編號：CONFLICT-003

## 狀態：`detected`

## 衝突描述
- **市場開發者** 需要：詳盡的銷售管道追蹤，記錄每次互動的時間、方式、結果，以及完整的客戶行為分析（US-MD-003、US-MD-004）
- **潛在客戶** 需要：自然的溝通體驗，不想感覺自己的每一步都被追蹤和分析（隱含於 US-PC-001 的尊重意願需求）
- **為什麼衝突**：市場開發者的管道追蹤越詳細，對潛在客戶來說可能越像「被監控」。如果客戶發現自己的社群互動、閱讀行為都被記錄，可能產生反感，特別是傳統產業客戶對數位追蹤技術的接受度可能較低。

## 衝突類型
**權限衝突**（追蹤透明度 vs. 溝通自然度）

## 相關 User Stories
- US-MD-003：銷售管道追蹤儀表板
- US-PC-001：尊重客戶意願

## AI 分析
此衝突在 B2B 銷售工具中很常見，但在針對傳統產業的場景中更為敏感。

關鍵觀察：
1. 傳統產業決策者可能對「被數位追蹤」更為敏感，因為他們的數位素養和對追蹤技術的理解程度較低
2. 社群媒體平台本身有使用條款限制自動化追蹤行為
3. 記錄互動是 CRM 的基本功能，關鍵在於追蹤的「範圍」和「方式」是否合理
4. 過度追蹤可能違反社群平台的服務條款，導致帳號被封禁

## 解決方案
- [ ] 方案 1：**僅記錄主動互動**（優先滿足潛在客戶）— 只記錄雙方有實際溝通的互動（如：訊息往來、會議紀錄），不追蹤被動行為（如：瀏覽紀錄、社群按讚）。CRM 功能聚焦於「關係管理」而非「行為監控」。
- [ ] 方案 2：**分階段追蹤**（折衷方案）— 初期接觸階段僅記錄基本互動（訊息已讀/回覆、會議時間）；進入深度溝通階段後，經客戶同意才啟用更詳細的互動記錄（如：提案查看次數、需求討論紀錄）。
- [ ] 方案 3：**完整追蹤 + 透明告知**（優先滿足市場開發者）— 記錄所有可追蹤的互動數據，但在首次接觸時即透明告知資料使用方式，並提供客戶隨時查看和刪除自己資料的權利。
